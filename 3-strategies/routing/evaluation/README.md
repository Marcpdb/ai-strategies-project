The findings of your Routing dashboard come here: one folder per run title you used (for example `baseline/`, `vary-input-budget-20/`), each with a `findings.md`.

In the dashboard, change what you want to test yourself (click In for the input, click a box for its prompt or model), give the run a title next to Run, and run it about 3 times. Type **findings** in Claude Code when you have run what you want to evaluate, starting with about 3 runs titled Baseline.
