# AI strategies project

This folder is a student's project on AI strategies and AI evaluation. Every folder that has work to do has its own `SKILL.md`: the instructions for that part.

- Read `SKILL.md` (this folder) at the start of every session. It covers "start", "sync", "status" and the manual dashboard.
- When the student works on a strategy ("build the parallel dashboard"), read `3-strategies/<strategy>/SKILL.md` and follow it.
- When the student asks for findings or about a test ("findings for chain", or is inside an evaluation folder), read `reference/evaluation.md` and the `SKILL.md` of each test folder, and follow them.
- For comparing strategies or the conclusion, read `4-compare-and-conclude/SKILL.md`.

If it is unclear which strategy or test the student means, ask. Write in plain English and keep answers short.
